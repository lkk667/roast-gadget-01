## The roast

> Every Monday, my phone sends me a screen-time report — a performance review from a boss who watched me scroll for nine hours and accomplish nothing.

148 characters. The phone is the gadget: it eats your attention all
week, then on Monday it puts on a tie and grades you for it. The roast
works because the phone is both the culprit and the auditor — no
battery complaint, no "it dies at 4pm" rerun, just the weekly report
turning into a performance review.

## The program

`main.py` (Python 3, standard library only) writes that one line to
`/output/entry.txt` — no trailing newline, no extra text — so the
entry passes the gate exactly as the rules require.

```sh
python3 main.py   # writes the 148-character roast to /output/entry.txt
```

Run twice, the output is byte-identical: the line is a constant, and
the program writes it verbatim.
